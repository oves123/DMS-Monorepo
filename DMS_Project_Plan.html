System Modules (SD + ND combined)

Anand Enterprises is a Super Distributor of "Anand Jolliz" snacks (Pidilite Chairman's Club Member) based in Ulhasnagar, Maharashtra. Currently all orders, billing, stock tracking, and payment collections are handled manually via paper and WhatsApp. This DMS will fully digitize the entire distribution operation.

── Supply Chain Flow ── Anand Jolliz (Manufacturer / Pidilite) ↓ sends stock Anand Enterprises (Super Distributor) ← This system manages this layer ↓ receives orders / dispatches goods Normal Distributors (Love Agency, Patel Traders, etc.) ↓ sells to shops Retailers / Shops
2
Technology Stack
⚛️ Frontend
React.js + Vite + TypeScript
Fast, component-based. TypeScript catches bugs at compile time. Same dev team already uses React. Files use .tsx extension.
🟩 Backend
Node.js + Express.js
Lightweight REST APIs. Same JavaScript language as frontend. Already used in other company projects. Files use .js extension.
🗄️ Database
Microsoft SQL Server (SSMS)
Reliable for financial/transactional data. Handles complex joins for reports. Team is already familiar with SSMS.
🔐 Authentication
JWT (JSON Web Tokens)
Stateless auth that works perfectly for multi-role systems (SD Admin, ND, Staff). Secure and industry standard.
🧾 PDF Invoices
pdfkit (server-side)
Generates professional GST/Non-GST invoice PDFs on the backend, matching the exact format of the current paper invoices.
📱 Mobile (Phase 2)
React Native
Same React knowledge transfers to mobile. Same backend APIs reused. Both iOS & Android from one codebase.
